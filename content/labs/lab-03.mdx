<Step n={3} title="for_all: ∀ as a loop" time="8 min" id="for-all">

**What:** `for_all(domain, P)` answers “is `P(x)` true for **every** `x` in the domain?”

**How:** go through the domain with a `for` loop. The moment you find an `x` where `P(x)` is false, you have a **counterexample**: return `False` immediately. If the loop ends without finding one, return `True`.

```python
for_all([2, 4, 6], lambda n: n % 2 == 0)    # True
for_all([2, 3, 6], lambda n: n % 2 == 0)    # False: 3 is a counterexample
for_all([], lambda n: False)                # True: nothing to break it
```

> [!warning] Write the loop yourself
> Do not use `all()` here. The checks look for it. The point is to see that “for all” **is** a loop that can stop early. The checks also verify that your loop stops at the first counterexample instead of looking at everything.

</Step>

<Step n={4} title="exists: ∃ as a loop" time="5 min" id="exists">

**What:** `exists(domain, P)` answers “is there **at least one** `x` with `P(x)` true?”

**How:** the mirror image of `for_all`. Return `True` at the first **witness**; if the loop ends, return `False`. Again, no `any()`.

```python
exists([1, 3, 4], lambda n: n % 2 == 0)     # True: 4 is a witness
exists([1, 3, 5], lambda n: n % 2 == 0)     # False
exists([], lambda n: True)                  # False: no witness in an empty domain
```

> [!tip] Why is `for_all([])` True but `exists([])` False?
> For ∀ to be false you need a counterexample, and an empty list has none. For ∃ to be true you need a witness, and an empty list has none. This is the “vacuous truth” from the notes.

</Step>

<Step n={5} title="counterexample and witness" time="5 min" id="ce-witness">

**What:** the same two loops, but instead of `True`/`False` they return the **element** they stopped at.

- `counterexample(domain, P)`: the first `x` with `P(x)` **false**, or `None`.
- `witness(domain, P)`: the first `x` with `P(x)` **true**, or `None`.

```python
counterexample([2, 3, 5], lambda n: n % 2 == 0)   # 3
witness([1, 3, 4, 6], lambda n: n % 2 == 0)       # 4
witness([1, 3], lambda n: n % 2 == 0)             # None
```

These are what a real program needs: not only “false”, but **who** made it false.

</Step>

<Step n={6} title="every_such_that and some_such_that: the golden rule" time="10 min" id="golden">

**What:** sentences like “**every** second-year knows Python” have a **filter** (A: is a second-year) and a **property** (B: knows Python). From the notes:

- “Every A is B” is **∀x (A(x) → B(x))**.
- “Some A is B” is **∃x (A(x) ∧ B(x))**.

**How:** build a new predicate and pass it to your own `for_all` or `exists`:

- for `every_such_that`: the predicate `lambda x: (not A(x)) or B(x)` (that is A → B),
- for `some_such_that`: the predicate `lambda x: A(x) and B(x)`.

```python
big  = lambda n: n > 2
even = lambda n: n % 2 == 0
every_such_that([1, 2, 3, 4], big, even)   # False: 3 is big but odd
every_such_that([1, 2, 4], big, even)      # True: the only big number, 4, is even
some_such_that([1, 2, 3], big, even)       # False: no big even number
```

> [!warning] The classic mistake, again
> If you write `A(x) and B(x)` inside `every_such_that`, the checks fail: that would say “**everything** is A and B”. Elements that do not pass the filter must never make a “for every A” sentence false.

</Step>

<Step n={8} title="not_all and not_any: De Morgan in code" time="8 min" id="de-morgan">

**What:** the two laws from the notes,

$$
\neg\forall x\, P(x) \;\equiv\; \exists x\, \neg P(x) \qquad\qquad \neg\exists x\, P(x) \;\equiv\; \forall x\, \neg P(x)
$$

**How:** write the **right-hand side**.

- `not_all(domain, P)`: call `exists` with a predicate that is the **opposite** of `P`: `lambda x: not P(x)`.
- `not_any(domain, P)`: call `for_all` with that opposite predicate.

The checks compare your answers with Python's `not all(...)` and `not any(...)` on 60 random lists, **and** read your code to make sure `not_all` really uses `exists` and `not_any` really uses `for_all`. Writing `not for_all(domain, P)` gives the right value but skips the law, so it does not pass.

</Step>
