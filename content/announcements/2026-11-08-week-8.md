**Monday, November 9 · [Week 8: Sets and Set Operations](/weeks/week-08).** A new module begins. Sets are the simplest data structure in mathematics, and almost everything else (relations, functions, graphs, every database table) is built from them. We cover set-builder notation, the difference between $\in$ and $\subseteq$ (and between $\emptyset$ and $\{\emptyset\}$), power sets, Cartesian products and the set operations, and we see that **every set identity is a logical equivalence from week 3 in disguise**. The notes include a **Venn lab** that checks any identity in $A$, $B$, $C$ and draws a counterexample when it fails, and light switches that show why a set with $n$ elements has $2^n$ subsets. Reading: Rosen 2.1–2.2.

**Lab 7 · [Sets and a Mini Recommender](/labs/lab-07)** opens right after the lecture. You will build the power set and the Cartesian product by hand, store sets as bit strings, write a checker that proves or breaks set identities, and finish with Jaccard similarity: a course recommender and a copied-text detector. Follow the steps in order; each one has an example and the expected result.
